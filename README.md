# 寿命倒计时桌面悬浮程序（Python/PyQt5）

## 功能简介
- 设置阳历生日和假设平均寿命
- 大数字展示已度过的天数，六宫格展示周岁 / 月 / 周 / 时 / 分 / 秒（大数字自动用万、亿格式化）
- 显示下一个生日倒计时（精确到秒）
- 生命进度条（紫→青渐变）+ 预计剩余寿命
- 现代深色界面：高对比度大字体、启动淡入、呼吸光晕、秒数闪动、进度条入场动画、卡片悬停高亮
- 支持悬浮窗拖动、透明度调节、系统托盘
- 界面大小可在设置中调整（80% ~ 200%），保存后立即生效
- 首次启动未设置生日时自动弹出设置窗口

## 调试运行方法
1. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
2. 启动程序：
   ```bash
   python main.py
   ```

## 打包发布
```bash
pyinstaller 人生倒计时.spec
```
打包产物输出到 `dist/人生倒计时.exe`。
