# ⏳ 人生倒计时桌面悬浮程序

一个用 Python / PyQt5 编写的 Windows 桌面悬浮窗程序：实时显示你已经活了多少天，距离下一个生日还有多久，以及按假设寿命估算的剩余时间。

![程序截图](./image.png)

## 功能特性

- **时间统计**：大数字展示已度过的总天数；六宫格实时显示周岁 / 月 / 周 / 小时 / 分钟 / 秒（超过百万自动格式化为「万」「亿」）
- **生日倒计时**：距离下一个生日的天数与时分秒；2 月 29 日生日自动按平年处理
- **生命进度**：紫→青渐变进度条展示生命进度百分比，并估算剩余寿命
- **动效**：启动淡入、呼吸光晕、秒数每秒闪动、进度条入场动画、卡片悬停高亮
- **悬浮窗**：无边框、可拖动、位置自动记忆；关闭即最小化到系统托盘
- **个性化**：界面大小（80% ~ 200%）与窗口透明度（30% ~ 100%）在设置中调整，保存即生效
- **新手友好**：首次启动未设置生日时自动弹出设置窗口

## 直接下载运行

1. 前往 [Releases](https://github.com/shenxian11/-life-countdown/releases/latest) 页面下载 `人生倒计时.exe`
2. 双击即可运行，无需安装 Python
3. 首次运行请点击窗口右上角 ⚙ 填写生日

## 调试运行方法

1. 安装依赖：

   ```bash
   pip install -r requirements.txt
   ```

2. 启动程序：

   ```bash
   python main.py
   ```

## 打包发布

```bash
pyinstaller 人生倒计时.spec
```

产物输出到 `dist/人生倒计时.exe`（单文件模式，图标已内置）。

## 配置文件

所有个人设置保存在程序同目录的 `config.json`，均可在设置窗口中修改：

| 字段 | 说明 | 默认值 |
| --- | --- | --- |
| birthday | 阳历生日（yyyy-MM-dd） | 无（首启引导填写） |
| lifetime | 假设寿命（岁） | 80 |
| ui_scale | 界面缩放（0.8 ~ 2.0） | 1.3 |
| opacity | 窗口不透明度（30 ~ 100） | 85 |
| window_pos | 窗口位置（拖动后自动保存） | - |
